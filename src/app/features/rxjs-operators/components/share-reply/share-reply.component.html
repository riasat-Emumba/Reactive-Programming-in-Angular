Share Reply Operator

The shareReplay operator is used to share the source observable with multiple subscribers and avoid multiple API calls. It is a combination of share and replay operators.

Conclusion

Initially, my API was being hit multiple times due to the repeated use of the observable. However, by using the shareReplay operator, the API is now hit only once. Subsequent data fetching does not involve any additional network requests, leading to improved performance and reduced load on the server.
